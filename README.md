# Frontend Mentor - QR code component

Opa! 👋 Este é um projeto simples feito como parte do desafio [QR Code Component](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) do Frontend Mentor.

## O que tem aqui? 🤔
- Um layout minimalista com HTML e CSS.
- Responsividade para ficar bonito em qualquer tela.
- Um QR Code estiloso, porque por que não, né? 😄

## O que aprendi 🚀
- Alinhar tudo direitinho com **Flexbox** (meu novo melhor amigo 🫶).  
- Usar **cores em HSL** pra dar aquele toque mais pro.  
- A importância de organizar o CSS pra não virar uma bagunça.  
- Pequenos ajustes pra deixar o design mais responsivo e acessível.

Foi divertido e me ajudou a melhorar minha atenção aos detalhes! 🎉
